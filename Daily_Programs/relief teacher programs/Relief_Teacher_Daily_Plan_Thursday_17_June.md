  -----------------------------------------------------------------------
  **Morning Session: Maths**
  -----------------------------------------------------------------------

  -----------------------------------------------------------------------

+-----------------------------------------------------------------------+
| **Task 1: Maths Sheets**                                              |
|                                                                       |
| There are 3 maths sheets available for students to complete.          |
|                                                                       |
| Students should begin with these sheets. They should work             |
| independently, show working where appropriate, and check their        |
| answers before moving on.                                             |
+=======================================================================+

+-----------------------------------------------------------------------+
| **Task 2: Maths Website Bug Testing**                                 |
|                                                                       |
| After completing or making strong progress on the maths sheets,       |
| students may access the maths website.                                |
|                                                                       |
| The students know how to find this site and are currently helping     |
| with bug testing.                                                     |
+=======================================================================+

**Website location:** Curriculum G → Common → Websites\_ →
Maths_Command_station → index.html

**Bug testing focus:**

- Use the site properly and test activities, buttons, links and pages.

- Notice anything confusing, broken, missing or not working as expected.

- Record the page/activity, what was clicked or typed, what happened,
  and what was expected.

- If the website does not work, students continue with maths sheets or
  other unfinished maths work.

  -----------------------------------------------------------------------
  **Middle Session: English**
  -----------------------------------------------------------------------

  -----------------------------------------------------------------------

+-----------------------------------------------------------------------+
| **Information Report Writing**                                        |
|                                                                       |
| Students write an information report on a topic of their choice.      |
|                                                                       |
| They already know how to write information reports. This is an        |
| opportunity for them to show what they know.                          |
|                                                                       |
| The provided information report lesson plan may be used as a guide if |
| needed.                                                               |
+=======================================================================+

**Writing options:** Students may complete this digitally or in their
English books.

  -----------------------------------------------------------------------
  **English Task Requirements**
  -----------------------------------------------------------------------

  -----------------------------------------------------------------------

+-----------------------------------+-----------------------------------+
| **Must include**                  | **Optional extras**               |
+===================================+===================================+
| - clear title                     | - labelled diagram                |
|                                   |                                   |
| - introduction                    | - fun facts box                   |
|                                   |                                   |
| - subheadings                     | - glossary                        |
|                                   |                                   |
| - organised sections              | - map                             |
|                                   |                                   |
| - factual information             | - timeline                        |
|                                   |                                   |
| - topic-specific vocabulary       | - comparison table                |
|                                   |                                   |
| - paragraphs                      | - image with caption              |
|                                   |                                   |
| - conclusion                      |                                   |
+-----------------------------------+-----------------------------------+

+-----------------------------------------------------------------------+
| **Suggested English Flow**                                            |
|                                                                       |
| 5 minutes: Quick reminder of information report features.             |
|                                                                       |
| 10 minutes: Topic choice and quick plan.                              |
|                                                                       |
| 30-40 minutes: Independent writing.                                   |
|                                                                       |
| 10 minutes: Edit and improve.                                         |
|                                                                       |
| If time allows: students share one interesting fact or strong         |
| paragraph with a partner.                                             |
+=======================================================================+

  -----------------------------------------------------------------------
  **Student Editing Checklist**
  -----------------------------------------------------------------------

  -----------------------------------------------------------------------

  --------------------------------------------------------------------
  **✓**   **Check**
  ------- ------------------------------------------------------------
  ☐       My title clearly names the topic.

  ☐       My introduction explains what the report is about.

  ☐       I have used subheadings.

  ☐       My facts are grouped into paragraphs.

  ☐       I have used topic-specific vocabulary.

  ☐       I have avoided too much personal opinion.

  ☐       My conclusion finishes the report properly.

  ☐       I have checked spelling, capital letters and full stops.
  --------------------------------------------------------------------

  -----------------------------------------------------------------------
  **Early Finisher Options**
  -----------------------------------------------------------------------

  -----------------------------------------------------------------------

- Continue maths sheets.

- Continue bug testing the maths website.

- Edit and improve the information report.

- Add a labelled diagram, glossary or fact box to the report.

- Read quietly.

- Continue approved coding work.

  -----------------------------------------------------------------------
  **Behaviour and Device Expectations**
  -----------------------------------------------------------------------

  -----------------------------------------------------------------------

- Follow normal classroom routines and teacher instructions.

- Use devices responsibly and stay on the assigned task.

- Work quietly during independent tasks.

- Speak respectfully and help others appropriately.

- Save digital work and close devices properly before pack-up.

- Minecraft is only available at the end of the day if the class earns
  it through good choices.

  **End of Day**
  -----------------------------------------------------------------------

  -----------------------------------------------------------------------

- Allow time for students to save digital work and close devices
  properly.

- Return maths sheets and tidy desks.

- Stack chairs if this is part of the normal routine.
