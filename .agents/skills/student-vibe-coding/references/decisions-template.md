# Student board template

Write `decisions.md` **to the student**. Short headings. Everyday words. No jargon.

Fill every section. If something does not apply (for example win/lose on a helper app), write one honest line, do not delete the heading.

Save as `Vibe_Coding/<short-slug>/decisions.md` unless a folder was already named.

```markdown
# <Title the student would say>

## My idea
<one or two sentences in the student's words, cleaned up>

## Version 1
<the first small thing we will make, in one or two sentences>
Version 1 means the first small game or app we actually make.

## How you play
<what you do over and over; keys, mouse, or tap>

## How you win or finish
<win, lose, or "you're done when…">

## How it looks and sounds
<setting, colours, characters; quiet beeps or silent>

## Later
<cool ideas we are saving, each on its own line>

## Not this time
<things we are skipping, with a kind reason>
```

## Filling rules

- Use the student's names for characters and places.
- If you took a recommended default because they shrugged, say so: "We picked arrow keys."
- **Later** is a treasure box, not a trash can. Keep their big dream visible.
- **Not this time** stays kind: "A whole 3D world is too big for Version 1" not "That's impossible."
- Do not copy `BUILD.md` into this file. This board is the student-facing map only.
