# Decision areas

Analyse the first request. Decide **game** or **helper app**. Load only that bank. Ask only decisions that still change Version 1.

A **game** is for playing. Fun is the point.
A **helper app** is for a job: practise spelling, make a poster, keep a list.

If it could be either, ask once: "Is this more like a game you play, or a helper that does a job?" Recommend the closer fit.

## Technical defaults (do not turn into a quiz)

Use these unless the student has a real reason not to:

| Default | Say it in kid language |
| --- | --- |
| Runs in the browser | Opens like a normal web page |
| 2D | Flat pictures, not a 3D world |
| One HTML file or a tiny folder | Easy to open at school |
| No accounts, no internet required | Works without signing in |
| Local save only, if anything is remembered | The computer remembers; nothing is sent away |
| Keyboard, mouse, or tap | Pick the simplest fit for the idea |

Do not offer Unity, Roblox Studio, servers, logins, or 3D worlds as Version 1 options.

## Always cover (both)

Settle these, from the request if possible, otherwise by asking:

1. **One sentence.** What is it?
2. **Who.** Usually the student and their class.
3. **Version 1 vs Later.** What is in the first small thing?
4. **Where it runs.** State the browser default.
5. **School-safe.** Original characters, school-okay action, no names/emails/photos collected. See [school-safe.md](school-safe.md).

## Games

Ask with concrete choices. Translate internally to a core loop: do something → the game answers → something good happens → repeat.

Hidden decisions to surface:

| Kid question | What you are really locking |
| --- | --- |
| What do you do over and over? | Core loop (the fun 10 seconds) |
| How do you start a round? | First screen and goal |
| How do you win, lose, or finish? | End states |
| Keys, mouse, or tap? | Controls |
| Where is it set, and what colours? | Look |
| Quiet beeps, or silent for class? | Sound |
| One player? | Players (Version 1 is one player) |

Typical Version 1 shapes (offer the closest, do not list all of them):

- Catch or dodge things that fall or fly
- Move through a short maze or obstacle path
- Tap or click the right thing in time
- A tiny quiz or memory match
- Collect items, then reach a goal
- A short clicker or builder with one craft or upgrade

Version 1 is one loop, one setting, one win/lose. Worlds, crafting trees, friends, and character creators go under Later.

## Helper apps

Hidden decisions to surface:

| Kid question | What you are really locking |
| --- | --- |
| What job does it do? | Purpose |
| What do you see first? | Home screen |
| What other pages do you need? | Screens (keep to 2–3) |
| Do you type, tap, or drag? | Input |
| Should it remember next time? | Local save or not |
| What does done look like? | Success |

Typical Version 1 shapes:

- Flashcards or a short quiz
- A list you can add to and tick off
- A simple maker: poster, comic panel, story page
- A timer or counter for a class job

No accounts. No sharing to the internet. No photos of real children.

## What not to ask yet

Skip until Version 1 is locked:

- Extra levels, worlds, or biomes
- Power-ups beyond one simple bonus
- Leaderboards, chat, or friends
- Custom characters with lots of parts
- Anything that needs a server

Write those under **Later** when the student mentions them.
