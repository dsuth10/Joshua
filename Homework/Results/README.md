# Homework Results Integration - Documentation

This directory contains the combined results of homework submissions across three different levels: **Red (Top)**, **Blue (Middle)**, and **Green (Bottom)**.

## Overview of Action Taken
The individual spreadsheets were merged into a single master file to centralize student data while preserving the unique context of each level's questions.

**Final File:** `Combined_Homework_Results.xlsx`

## Data Structure

### 1. The "Level" Column
A new column named **Level** was added at the start of the spreadsheet (Column A). This identifies the source of the row:
*   `Red`: Top level students
*   `Blue`: Middle level students
*   `Green`: Bottom level students

### 2. Header Suffixes
To prevent the accidental merging of different questions that might share similar names (e.g., "Question 1"), all question-related headers have been appended with their respective level in parentheses:
*   Example: `What is 256 ÷ 8? (Red)`
*   Example: `What is 256 ÷ 8? (Blue)`

This ensures that even if a question appears in multiple levels, the data remains distinct and searchable by level.

### 3. Column Layout
The spreadsheet is structured in the following order:
1.  **Level Identifier**: (Red/Blue/Green)
2.  **Student Metadata**: Standard fields that are common to all levels:
    *   ID
    *   Start time / Completion time
    *   Email
    *   Name
    *   Total points
    *   Quiz feedback
    *   Last modified time
3.  **Level-Specific Questions**: All unique questions, points, and feedback columns from each level are laid out horizontally. 
    *   *Note: If a student was in the 'Red' level, their data will appear in the 'Red' question columns, and the 'Blue' and 'Green' question columns for that row will be empty (NaN).*

## Technical Details
*   **Merge Logic**: The files were processed using Python (Pandas). 
*   **Total Columns**: 261
*   **Total Records**: 10 (at time of creation)
*   **Handling Repeating Students**: The merge allows for repeating students. If a student moves between levels, they will appear as two separate rows, each identifying their respective level and performance at that time.
