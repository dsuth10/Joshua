# Maths Command Station: Curriculum Subdivision & Achievement System Proposal

This document outlines the analysis and proposed implementation strategy for migrating the Maths Command Station's progress and achievement system from six broad strands to granular, Australian Curriculum v9 (AC v9) Content Descriptors.

---

## 📋 Executive Summary
* **Current State**: Students earn points per question across six high-level strands (`number`, `algebra`, `measurement`, `space`, `statistics`, `probability`). High-level badges are awarded for reaching $100\text{ pts}$ in a strand, along with a few streak badges.
* **Proposed State**:
  1. **Subdivide Strands**: Directly map question types to individual AC v9 Content Descriptors (e.g., `AC9M5N01` for Year 5 Decimal Place Value).
  2. **Student-Friendly Achievements**: Create a dedicated, engaging badge for every content descriptor (e.g., *Decimal Precisionist* for `AC9M5N01`).
  3. **Multi-Context Mastery**: Require students to earn points in different question contexts (e.g., calculation vs. visual tools vs. word problems) to unlock each descriptor's badge.
  4. **Dynamic Badge Shelf**: Render the badge shelf dynamically based on the student's granular profile database, replacing hardcoded HTML lists.

## 🏗️ Technical Architecture & Profile Migration Plan

To avoid bloating the codebase and to maintain perfect compatibility with existing saved profiles, the following architecture is proposed:

### 1. Granular Progress Tracking Schema
We expand the local student profile structure to include a `scoresByDescriptor` map, which records points specifically per content descriptor. The high-level strand points can be calculated dynamically as the sum of their children:

```javascript
const profile = {
    name: 'ENGINEER',
    score: 0,
    level: 1,
    streak: 0,
    highestStreak: 0,
    rank: 'Novice Calibrator',
    badges: [], // Array of unlocked badge IDs (e.g. ['ac9m5n01', 'streak-5'])
    scoresByDescriptor: {
        // e.g., 'ac9m5n01': 45
    },
    // Keep for backwards compatibility & quick UI updates:
    scoresByCatY5: { number: 0, algebra: 0, measurement: 0, space: 0, statistics: 0, probability: 0 },
    scoresByCatY4: { number: 0, algebra: 0, measurement: 0, space: 0, statistics: 0, probability: 0 },
    scoresByCatY3: { number: 0, algebra: 0, measurement: 0, space: 0, statistics: 0, probability: 0 }
};
```

### 2. Backward Compatibility & Migration
Upon loading a profile from `localStorage`:
* If `scoresByDescriptor` does not exist, initialize it as empty.
* If legacy strand scores (like `scoresByCatY5.number = 150`) exist, we map a baseline proportion of those points (e.g., divided evenly) into the corresponding descriptor keys so students do not lose their progress.
* When points are gained:
  1. Add points to `profile.score`.
  2. Add points to the specific descriptor in `profile.scoresByDescriptor[descriptorCode]`.
  3. Re-calculate the parent strand score (e.g., `scoresByCatY5.number`) by summing the corresponding descriptors.

## 🎖️ Achievement Unlocking Rules (Multi-Context Mastery)

Instead of just checking points, badges are unlocked when the student demonstrates understanding across multiple contexts. 

### Proposal: Multi-Context Criteria
A badge for a descriptor (e.g., `AC9M5N01`) is unlocked when the student satisfies:
1. **Total Points**: Earn at least $50\text{ pts}$ in that descriptor.
2. **Context Diversity**: Complete at least one question of type **A** (e.g., interactive/visual tool) and one of type **B** (e.g., word problem/calculation) under that descriptor.
3. **Accuracy Test**: Solve at least two consecutive questions correctly.

### Schema definition (`achievements-config.js`)
We will create a centralized javascript configuration that holds the meta-information for the badges. This makes the UI completely data-driven:

```javascript
const DESCRIPTOR_BADGES = {
    'ac9m5n01': {
        code: 'AC9M5N01',
        year: 5,
        strand: 'number',
        badgeName: 'Decimal Precisionist',
        emoji: '🔢',
        desc: 'Mastered ordering and comparing decimals with more than 2 decimal places using place value and number lines.',
        requirements: {
            points: 50,
            contexts: ['decimal-sorting', 'number-line-plots']
        }
    },
    'ac9m5m02': {
        code: 'AC9M5M02',
        year: 5,
        strand: 'measurement',
        badgeName: 'Precision Builder',
        emoji: '📐',
        desc: 'Mastered solving practical problems involving the perimeter and area of regular and irregular shapes.',
        requirements: {
            points: 50,
            contexts: ['perimeter-irregular', 'area-compound']
        }
    }
    // ... all other descriptors
};
```

### Dynamic Badge Shelf Rendering
Instead of writing static HTML with hardcoded tooltip attributes for every badge in `year3-practice.html`, `year4-practice.html`, and `year5-practice.html`, we will use JS to query `DESCRIPTOR_BADGES` for the active year level and render the badge icons dynamically. Unlocked badges will have active click handlers, showing the certificate overlay.

## 🏆 Strand Mastery Awards (Grand Badges)

To provide an impressive milestone incentive, students will earn **Strand Mastery Awards (Grand Badges)** when they unlock every single content descriptor badge for a specific strand and year level.

### Grand Badge Mechanics
* **Trigger**: Automatically evaluated whenever a descriptor badge is unlocked.
* **Condition**: `profile.badges` contains all content descriptors matching a specific year and strand (e.g. all Year 5 Measurement descriptors: `AC9M5M01`, `AC9M5M02`, `AC9M5M03`, `AC9M5M04`).
* **Visual Presentation**: Grand Badges will have a unique, prestigious design, such as an ornate gold border, animated glowing backdrops, and a large custom emoji/symbol.

### Grand Badge Registry Example


## 🏛️ Dedicated Achievement Dashboard ("The Trophy Room")

To prevent the practice screen's side panel from becoming cluttered and overwhelming, we propose a dedicated UI overlay or separate tab called **The Trophy Room**. 

### 1. UX Structure
* **Entrance**: A sleek "View Trophy Room 🏆" button in the profile header panel.
* **Layout**: A responsive grid structured by **Year Level** (Tabs/Filters for Year 3, 4, 5, 6) and subdivided by **Strand**.
* **Visual Hierarchy**:
  * **Top Section**: Displays the active level, total score, and a prominent display of unlocked **Strand Mastery Grand Badges** in a shimmering showcase.
  * **Strand Sections**: Each strand (e.g., Number) is displayed as a card containing:
    * A horizontal progress bar: "3 / 10 Badges Collected".
    * A grid of individual descriptor badges. Locked badges are semi-transparent with a lock icon, but hoverable to show the requirement (e.g., "Earn 50 pts in AC9M5N01"). Unlocked badges glow in their strand-specific colour.

### 2. The Certificate Modal
When a student clicks an unlocked badge (either in the sidebar shelf or the Trophy Room):
* It opens a full-screen blurred-backdrop modal displaying a high-fidelity **Certificate of Achievement**.
* The certificate pre-fills the student's name and date.
* Students can click "Print as PDF" which triggers a CSS `@media print` print-sheet, perfectly formatted as a standard A4 landscape certificate suitable for framing or sharing.
