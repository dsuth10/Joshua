**Plan**

The components of the Steady Hand Game have been removed from the game so that you can test each one separately to identify why the game doesn’t work properly.

- You will build a circuit to test each of these components from the game:

- Wire course

- Wire loop, handle and connecting wire

- Light bulb

- Buzzer

- In the first box below, draw a labelled diagram of how you will set up your testing circuit.

- In the second box, draw a circuit diagram of the testing circuit you will build. **Hint:** use the following symbols in your circuit diagram.

Student responses to this question may vary, as the arrangement of the electrical components is unimportant. Responses should:

- represent an open circuit with a gap where components to be tested will be inserted

- include appropriate components connected in series, i.e. cell or series of cells, wires

- include a way of observing that the inserted component is working properly, e.g. light bulb.
