| Lessons 1--2                                                                                                          | Understanding environments --- Identifying and profiling habitats                                                                                                         |
+-----------------------------------------------------------------------------------------------------------------------+---------------------------------------------------------+-----------------------------------------------------------------------------------------------------------------+
| Lesson concepts                                                                                                                                                                 | Example learning sequence                                                                                       |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | Identify features of a local habitat                                                                            |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Discuss the meaning of the words:                                                                             |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | <!-- -->                                                                                                        |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - 'environment' --- all the living and non-living things that make up a particular area                         |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - 'habitat' --- the place in an environment where a living thing normally lives                                 |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - 'field work' --- where scientists take measurements and make observations about things in their natural       |
|                                                                                                                                                                                 |   place.                                                                                                        |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | <!-- -->                                                                                                        |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Review the requirements of living things.                                                                     |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Participate in local field work to:                                                                           |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | <!-- -->                                                                                                        |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - identify features of a local habitat                                                                          |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - collect data that describes a local habitat.                                                                  |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | Collect evidence that the environment supports life                                                             |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Conduct field observations of the local area.                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Use evidence of animals' presence to indicate animal activity:                                                |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | <!-- -->                                                                                                        |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Scat (animal droppings)                                                                                       |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Tracks and trails                                                                                             |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Nests                                                                                                         |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Evidence of eating                                                                                            |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Skin                                                                                                          |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Exoskeletons (the hard body covering of insects)                                                              |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Carcasses (the dead bodies of animals)                                                                        |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | Establish pan traps in the local area                                                                           |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Follow guidelines to set up pan traps around the local area.                                                  |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Discuss the proper treatment of any animals that are caught in the pan trap.                                  |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Ensure that proper procedures are followed when setting these traps.                                          |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Predict what types of animals the pan traps may catch.                                                        |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Check traps daily in order to ensure animals are not harmed unnecessarily.                                    |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Ensure that all animals caught by the pan traps are photographed and then carefully released.                 |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | Link features of a local habitat to growth and survival of living things                                        |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Explore the features of the local habitat and describe how they relate to the survival of living things.      |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Discuss the range of animals and plants that might be found in the studied habitat.                           |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Review the link between different environmental conditions and features of animals and plants.                |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | Collect information from field work                                                                             |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Collate the class's information from students' individual field work.                                         |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Display images of the animals collected in the pan traps.                                                     |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Explore the similarities and differences between the individual habitats studied.                             |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Create a profile for the local habitats studied as a whole group.                                             |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | Discuss reasons for conducting field work                                                                       |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Identify reasons why field work is important.                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Explore different professions that may need to conduct field work to study environments in various            |
|                                                                                                                                                                                 |   ecosystems.                                                                                                   |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Understand that an ecosystem is all the organisms of multiple species interacting with each other in an area  |
|                                                                                                                                                                                 |   and the non-living factors that affect them.                                                                  |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Explain how field work contributes to the understanding of the local environment.                             |
|                                                                                                                                                                                 |                                                                                                                 |

| Lesson objectives                                                                                                                                                               |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Students will:                                                                                                                                                                  |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Collect data during field work.                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Relate environmental features to types of animals and plants in a specific habitat.                                                                                             |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Evidence of learning                                                                                                                                                            |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Can the student:                                                                                                                                                                |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Collect and record field work data relating to a local habitat?                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Link environmental features to types of animals and plants?                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Ideas for monitoring                                                                                                                                                            |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Monitor students' ability to:                                                                                                                                                   |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Record data relating to a local habitat.                                                                                                                                        |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Identify relationships between environmental data and types of plants and animals.                                                                                              |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Learning alerts                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Be aware of:                                                                                                                                                                    |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Students thinking that the terms 'environment' and 'habitat' have similar meanings.                                                                                             |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Suggested next steps for learning                                                                                                                                               |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Explain to students that environment refers to all of the conditions in an area, whereas a habitat is the place in the environment where an organism lives.                     |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Ideas for differentiation                                                                                                                                                       |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Support                                                                                                                                                                         |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Choose an area of the local environment that contains easily recognisable signs of animal activity and suitable plant life for cataloguing.                                     |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Extension                                                                                                                                                                       |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Ask students to compare what they discovered in their local habitat to what they could expect in different habitat, e.g. a rainforest, a desert.                                |                                                                                                                 |
