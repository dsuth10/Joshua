|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | Explore the link between observations and recommendations                                                       |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Describe the link between making observations about an environment and the recommendations that can be made   |
|                                                                                                                                                                                 |   to improve its state.                                                                                         |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Identify ways to improve a pond's environmental condition using the learning object *Old Bernie's pond*.      |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Describe choices that seemed worthwhile, but resulted in a negative impact on the pond health.                |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | Conduct an investigation into environmental changes                                                             |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Conduct an investigation into physical changes in an example environment.                                     |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | <!-- -->                                                                                                        |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Identify changes to a natural environment.                                                                    |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Predict the effect of a building development on the animals and plants in the environment.                    |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Graphically represent the number of frog eggs in the pond during the building development.                    |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Explain changes in the pond ecosystem using data collected.                                                   |
|                                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 | - Describe actions that could be taken to minimise the impact of the building development.                      |

| Evidence of learning                                                                                                                                                            |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Can the student:                                                                                                                                                                |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Evaluate data and draw conclusions about the effect on living things of changing the environment?                                                                               |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Use data to make suggestions to improve an environment for living things to grow and survive?                                                                                   |                                                                                                                 |

|                                                                                                                                                                                 |                                                                                                                 |
| Identify and evaluate the effects of changing an environment.                                                                                                                   |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Make suggestions to improve an environment for living things to grow and survive.                                                                                               |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Learning alerts                                                                                                                                                                 |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Be aware of:                                                                                                                                                                    |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Students thinking that by removing something that has damaged an environment it will revert to its natural state.                                                               |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Suggested next steps for learning                                                                                                                                               |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Inform students that it can take many years and some human assistance to return damaged environments to their natural state.                                                    |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Ideas for differentiation                                                                                                                                                       |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Support                                                                                                                                                                         |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Provide students with scaffolding when using the learning object. Ensure that students record each of their choices and the impact it has on the pond environment.              |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Extension                                                                                                                                                                       |                                                                                                                 |
|                                                                                                                                                                                 |                                                                                                                 |
| Ask students to describe the impact that a building development would have on their local area. Ask students to provide recommendations for minimising this impact.             |                                                                                                                 |
