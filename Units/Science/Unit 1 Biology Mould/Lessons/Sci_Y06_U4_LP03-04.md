+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+---------------------------------------------------------+-----------------------------------------------------------------------------------------------------------------+
| Lesson concepts                                                                                                                                                                                                                                                     | Example learning sequence                                                                                       |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | Identify environmental factors affecting plant growth                                                           |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Discuss the different environmental factors that may affect plant growth, including:                          |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | <!-- -->                                                                                                        |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - salinity (amount of salt)                                                                                     |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - temperature                                                                                                   |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - water availability                                                                                            |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - sunlight.                                                                                                     |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | <!-- -->                                                                                                        |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Predict whether these environmental factors could have a positive or negative impact on plant growth.         |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | Conduct a simulation to investigate germination of plants                                                       |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Discuss (e.g. view a slideshow) planning and conducting investigations using fair testing.                    |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Review the concept of a fair test as an investigation where one variable is changed, one is measured and      |
|                                                                                                                                                                                                                                                                     |   everything else is kept the same.                                                                             |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Using the learning object *Fair test* and follow instructions to investigate the effects of environmental     |
|                                                                                                                                                                                                                                                                     |   changes on when a plant germinates or grows.                                                                  |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | <!-- -->                                                                                                        |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Identify variables to be measured, changed and controlled.                                                    |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Pose an investigable question to be answered by the investigation.                                            |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Predict the outcome of the investigation that demonstrates a simple cause-and-effect relationship.            |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | <!-- -->                                                                                                        |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Jointly plan the method for this investigation. (This may vary depending on the variables changed and         |
|                                                                                                                                                                                                                                                                     |   measured.)                                                                                                    |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Conduct the investigation using the online simulation.                                                        |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Record the results of this investigation.                                                                     |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | Graph relevant data using online tools                                                                          |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Construct a graph of the recorded data using online graph makers.                                             |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Identify all the important features of a graph.                                                               |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Use the constructed graphs to write a conclusion to the investigation.                                        |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | Conduct a fair test independently                                                                               |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Record (e.g. use a learning object or Science journal) the steps needed to conduct a fair test:               |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | <!-- -->                                                                                                        |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Identify variables to be measured, changed and controlled.                                                    |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Pose a scientific question to be answered by the investigation.                                               |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Predict the outcome of the investigation that demonstrates a simple cause-and-effect relationship.            |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Plan the steps to be taken in the investigation.                                                              |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Conduct the investigation.                                                                                    |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Record and present the data gained through the investigation.                                                 |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | <!-- -->                                                                                                        |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Present the findings of the investigation to the class.                                                       |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | Identify environmental factors affecting growth                                                                 |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Identify the environmental factors considered, e.g. nutrients (liquid solution), type of light, light         |
|                                                                                                                                                                                                                                                                     |   intensity, light duration, temperature, amount of water.                                                      |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Describe the effect that different environmental factors had on the growth of the plants in the simulation.   |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Categorise these effects as either positive or negative.                                                      |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Discuss how scientific knowledge about growth of plants can be used to solve problems and inform personal and |
|                                                                                                                                                                                                                                                                     |   community decisions.                                                                                          |
|                                                                                                                                                                                                                                                                     |                                                                                                                 |
|                                                                                                                                                                                                                                                                     | - Explore how understanding factors that affect plant growth can be used by people in their occupations and     |
|                                                                                                                                                                                                                                                                     |   daily lives.                                                                                                  |
