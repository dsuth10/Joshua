# GRID REFERENCE RULES

## THE GOLDEN RULE:
### **"You have to RUN before you can JUMP!"**

---

### **1. THE X-AXIS (RUN)**
- Go **ACROSS** first.
- This is the **FIRST** number in the brackets.
- ( **X**, Y )

---

### **2. THE Y-AXIS (JUMP)**
- Go **UP** second.
- This is the **SECOND** number in the brackets.
- ( X, **Y** )

---

### **3. THE ORIGIN**
- Start at **(0, 0)**.
- This is the bottom-left corner!

---

### **EXAMPLE:**
**To find (3, 4)**
1. **RUN** 3 steps across.
2. **JUMP** 4 steps up.
