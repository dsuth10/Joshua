# Lesson Plan: Introduction to Grid Coordinates

## Learning Intention
Students will understand how to use a grid coordinate system to locate positions in the first quadrant, specifically identifying the X-axis (horizontal) and Y-axis (vertical).

## Success Criteria
1.  I can identify the X and Y axes on a grid.
2.  I can state the X-coordinate first and the Y-coordinate second.
3.  I can find a point on a grid using a coordinate pair (X, Y).
4.  I can remember the rule: "Run along the floor before you jump up the stairs."

## Curriculum Alignment
**[AC9M5SP02]**: Construct a grid coordinate system that uses coordinates to locate positions within a space; use coordinates and directional language to describe position and movement.

---

## Lesson Sequence

### 1. Introduction (10 mins)
- **Concept Hook**: Show students a blank grid. Ask: "How can we tell someone *exactly* where a point is without pointing?"
- **The Vocabulary**:
    - **Origin**: The starting point (0, 0).
    - **X-axis**: The horizontal line (going across).
    - **Y-axis**: The vertical line (going up).
    - **Coordinates**: A pair of numbers that show a position.

### 2. The Golden Rule (5 mins)
- **Mnemonic**: "You have to run before you can jump."
- **Explanation**:
    1.  **Run**: Move along the X-axis (Horizontal) first.
    2.  **Jump**: Move up the Y-axis (Vertical) second.
- **Reference**: (x, y) = (Run, Jump).

### 3. Confidence Booster Examples (15 mins)
*Refer to the PowerPoint slides for these visual examples.*

#### Example 1: The Treasure Map
- Point at a "Treasure Chest" on a 5x5 grid at (3, 2).
- **Teacher Guide**: "First, we run 3 steps across the X-axis. Then, we jump 2 steps up the Y-axis. Where is the treasure? At (3, 2)!"

#### Example 2: The Flying Rocket
- Point at a "Rocket" at (1, 4).
- **Teacher Guide**: "We run 1 step across. We jump 4 steps up. The coordinates are (1, 4)."

### 4. Guided Practice (15 mins)
- Use the **Grid Coordinates Lesson 1.pdf** worksheet.
- Complete the first three questions together as a class.
- Focus on the "Reading the first number is the X axis" rule.

### 5. Independent Task (15 mins)
- Students complete the remaining questions on the worksheet.
- Support students who struggle with the order (swapping X and Y).

### 6. Plenary & Success Check (5 mins)
- Revisit Success Criteria.
- Quick Fire Round: Call out coordinates and have students "air-draw" the path (Run then Jump).

---

## Differentiation
- **Support**: Provide a "Grid Reference Rules" poster and a physical grid with labels "RUN" (X) and "JUMP" (Y).
- **Extension**: Ask students to write a secret code for their partner to find a "hidden island" on a larger grid.
