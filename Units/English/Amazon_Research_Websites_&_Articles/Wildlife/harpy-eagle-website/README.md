# Harpy Eagle: Crowned Giant of the Canopy on Thin Branches

An interactive, responsive website showcasing the majestic harpy eagle, the largest eagle in the Americas and a keystone species of the Amazon rainforest. This website combines stunning visuals with comprehensive information about these magnificent birds of prey.

## 🌟 Features

### Interactive Elements
- **Smooth Scrolling Navigation**: Seamless navigation between sections
- **Mobile-Responsive Design**: Optimized for all device sizes
- **Scroll Animations**: Parallax effects and scroll-triggered animations
- **Counter Animations**: Animated statistics that count up on scroll
- **Typing Effect**: Dynamic hero title with typing animation
- **Hover Effects**: Interactive cards and buttons with smooth transitions
- **Progress Bar**: Visual scroll progress indicator
- **Back-to-Top Button**: Easy navigation to the top of the page
- **Loading Animations**: Smooth page load transitions
- **Lazy Loading**: Optimized image loading for better performance

### Accessibility Features
- **Keyboard Navigation**: Full keyboard accessibility
- **Focus Management**: Proper focus indicators and management
- **Semantic HTML**: Screen reader friendly structure
- **ARIA Labels**: Proper accessibility attributes
- **High Contrast**: Readable color scheme

### Content Sections
- **Hero Section**: Stunning visual introduction with key statistics
- **About Section**: Detailed information about harpy eagle characteristics
- **Lifestyle Section**: Habitat and behavioral information
- **Diet Section**: Hunting strategies and prey preferences
- **Adaptations Section**: Specialized physical and behavioral adaptations
- **Ecological Role**: Importance as umbrella species
- **Threats Section**: Conservation challenges and threats
- **Conservation Section**: Current protection efforts and success stories

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional software required

### Installation
1. Download or clone the project files
2. Open `index.html` in your web browser
3. Enjoy exploring the harpy eagle website!

### Local Development
```bash
# Navigate to the project directory
cd harpy-eagle-website

# Open in your preferred browser
start index.html  # Windows
open index.html   # macOS
xdg-open index.html  # Linux
```

## 🔧 Customization

### Colors
Modify the CSS custom properties in `styles.css`:
```css
:root {
    --primary-green: #2c5530;
    --primary-blue: #4a90e2;
    --accent-gold: #ffd700;
    /* Add your custom colors here */
}
```

### Content
- Update text content in `index.html`
- Replace images with your own (maintain aspect ratios)
- Modify statistics and facts as needed

### Styling
- Adjust animations in `styles.css`
- Modify layout in the CSS Grid and Flexbox sections
- Update responsive breakpoints as needed
