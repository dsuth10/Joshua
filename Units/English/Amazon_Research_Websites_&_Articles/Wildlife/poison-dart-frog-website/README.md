# Poison Dart Frog: Tiny Jewels with a Deadly Secret

An interactive website showcasing the fascinating world of poison dart frogs, their unique adaptations, and the conservation challenges they face in the Amazon rainforest.

## 🌟 Features

- **Interactive Hero Section**: Stunning visual introduction with key statistics
- **Comprehensive Information**: Detailed sections covering habitat, diet, adaptations, and threats
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Smooth Navigation**: Fixed navigation bar with smooth scrolling
- **Conservation Focus**: Dedicated sections on threats and conservation efforts
- **External Resources**: Links to authoritative conservation organizations

## 📁 File Structure

```
poison-dart-frog-website/
├── index.html          # Main HTML file with all content
├── styles.css          # Complete styling and responsive design
├── script.js           # Interactive functionality and animations
└── README.md           # This documentation file
```

## 🚀 Installation

1. **Clone or Download**: Get the website files into your local directory
2. **Navigate**: Open the `poison-dart-frog-website` folder
3. **Open**: Double-click `index.html` or open it in your web browser

## 💻 Local Development

### Quick Start
```powershell
# Navigate to the website directory
cd poison-dart-frog-website

# Open in default browser (Windows)
start index.html

# Or open with a specific browser
start chrome index.html
```

### Using a Local Server (Recommended)
```powershell
# Using Python (if installed)
python -m http.server 8000

# Using Node.js (if installed)
npx serve .

# Using PHP (if installed)
php -S localhost:8000
```

Then open `http://localhost:8000` in your browser.
