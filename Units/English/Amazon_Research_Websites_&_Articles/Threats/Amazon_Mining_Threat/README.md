# Gold Rush Peril: Amazon Mining Threat Website

This interactive website presents how mining—especially gold—threatens the Amazon rainforest’s wildlife and people. It follows the same design and interactivity as the other sites (Inter font, gradients, grid/flex, animations, smooth scrolling, mobile nav, parallax, counters, progress bar, back-to-top, lazy loading, accessibility).

## Structure

```
amazon-mining-threat-website/

├── styles.css        # copied from anteater-website

└── README.md
```

## Sections
- Hero: Title, summary, statistics, and hero image
- About: Tapir, ocelot, primates; diet/adaptations; ecosystem roles
- Impact: Mercury poisoning, aquatic/mammal impacts, habitat destruction, Indigenous communities
- Causes: Economic/social drivers; illegal trade & demand
- Solutions: Enforcement, monitoring, international partnerships, legislation; initiatives
- Action: Support organizations and awareness
- References: Complete list of citations with links
