# Amazon Rainforest Under Siege: Deforestation Threat Website

This interactive website presents the causes, impacts, and solutions to Amazon rainforest deforestation using a modern, animated design and the shared template from existing animal websites. All content is adapted from `amazon-deforestation-threat.md`, with references integrated as clickable links.

## Features
- Smooth scrolling, mobile navigation, and keyboard accessibility
- Scroll-triggered animations and subtle parallax
- Typing effect for hero title and animated counters
- Progress bar, back-to-top button, loading animation
- Lazy-loaded images with graceful fallbacks
- Responsive layout using Flexbox and CSS Grid

## Sections
- Hero: Title, intro context, key statistics (area, species, loss rate)
- About: Jaguars, toucans, sloths (roles, adaptations) with links
- Impact: Fragmentation, jaguars, birds, extinction debt, fire imagery
- Causes: Cattle, soy, palm/industrial ag, mining & roads
- Economic/Political Drivers: Profit incentives, deregulation, land tenure
- Solutions: Enforcement, Amazon Fund, monitoring, protected areas, indigenous stewardship, traceability, corridors, cooperation
- Take Action: Support organizations, consumer choices, advocacy/awareness
- References: Complete list of citations with links
