# Amazon Field Guide

Year 5 research source articles about Amazon wildlife and threats.

## How to open

Open [`index.html`](index.html) in a browser (double-click or `file://`). All photos live in `assets/img/`, so pages work offline.

## Structure

```
Amazon_Research_Websites_&_Articles/
  index.html                 ← hub / contents
  assets/
    magazine.css             ← shared earthy magazine styles
    magazine.js              ← tiny contents-rail highlighter only
    img/                     ← local photos
  Wildlife/<topic>-website/index.html
  Threats/Amazon_*_Threat/index.html
```

Each article is a single `index.html` linking the shared CSS/JS. There are no per-folder `styles.css` or heavy animation scripts.

## Design

- Earthy palette (bark, clay, ochre, moss, cream paper)
- Magazine furniture: masthead, field notes, feature read, numbered explainer, stat band, survivor list, odd facts, word bank, sources
- No typewriter, parallax, counters, or scroll pop-ins
- System serif fonts only (no Google Fonts / Font Awesome)

## Articles

**Wildlife (10):** jaguar, sloth, piranha, poison dart frog, leafcutter ant, harpy eagle, anteater, giant otter, Amazon river dolphin, macaw

**Threats (3):** deforestation, mining, poaching
