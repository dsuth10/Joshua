# Lesson 8 — Week 2

| | |
|---|---|
| **Book** | *The Long Road Home* (Alba Series, Book 8) |
| **Phonics Focus** | 'oe' sound — o-e, ow, oa, o |
| **Writing Focus** | Recount with character focus: Retelling from a character's perspective |
| **Week Theme** | Building Blocks: Recounting and Character Descriptions |

---

## Learning Intentions

- **Reading:** I am learning to read words where the long 'o' sound is spelled different ways (o-e, ow, oa)
- **Writing:** I am learning to combine recounting AND character description by retelling from Alba's point of view
- **Spelling:** I am learning the different ways to spell the long 'o' sound

## Success Criteria

- I can read words with o-e, ow, and oa in the story
- I can write a 3–4 sentence recount that includes how the character felt
- I can spell at least 3 words with long 'o' patterns correctly

---

## Reading (≈20 minutes)

### Introduction (5 min)
- "We're up to Book 8 now — more than halfway through Alba's adventure! Let's see what happens."
- Show *The Long Road Home*. "Where do you think Alba is trying to get to? What might happen on the way?"
- **Phonics preview:** Write long 'o' examples:

| o-e | ow | oa | o |
|-----|-----|-----|---|
| home | grow | road | go |
| bone | slow | boat | so |
| stone | show | coat | no |

- "All of these have the /oʊ/ sound, but they're spelled in four different ways!"

### Guided Reading (10 min)
- Lucas reads *The Long Road Home* aloud.
- Prompt for long 'o' words: "What spelling is the /oʊ/ sound using here?"
- **Character lens reading:** While reading, prompt: "How is Alba feeling right now? What word or picture tells you that?"
- Pause at key moments: "If you were Alba, what would you be thinking?"

### Comprehension (5 min)
- **Perspective:** "Tell me what happened — but tell me as if YOU are Alba. Start with 'I'..."
- **Literal:** "What was the road like? What did Alba see on the way?"
- **Cross-book connection:** "How is this story similar to *Lost* (Book 1)? How is it different?"

---

## Writing (≈25 minutes)

### Explicit Teaching: First-Person Recount (5 min)
- Explain: "Today we're going to combine what we learned about recounts AND character description."
- Model: Instead of writing "Alba walked down the road", we write it from HER perspective:
  - *"First, I walked down the long road. I felt tired and scared. Next, I saw a big tree and hid behind it."*
- Point out: "We use 'I' instead of 'Alba'. We include HOW she feels. It's a recount PLUS character feelings."
- Compare a plain recount vs a character-focused recount side by side on the whiteboard.

### Guided Writing (10 min)
- Plan together using the 4-box template from Lesson 5, but add a "feelings" row:

| | First | Next | Then | Finally |
|---|-------|------|------|---------|
| **Event** | | | | |
| **Feeling** | | | | |

- Fill in events and feelings together from *The Long Road Home*.
- Write 2 sentences together, showing how to include the feeling:
  - *"First, I started walking down the road. I felt brave but a bit worried."*

### Independent Writing (10 min)
- Lucas writes a 3–4 sentence first-person recount of *The Long Road Home*.
- **Requirements:**
  - Use at least 2 sequence words
  - Include at least 1 sentence about how Alba felt
  - Use "I" instead of "Alba"
- Teacher aide supports as needed, noting progress on both recount structure and character insight.

---

## Spelling (≈15 minutes)

### Pattern Discrimination (5 min)
- Teacher aide says a word. Lucas writes it on the whiteboard, choosing the correct long 'o' spelling.
- After each attempt, reveal the correct spelling and discuss:
  - "Road — is it rod, rode, road, or rowd?" → **oa** in the middle
  - "Home — h-o-m-e" → **o-e** (split digraph)
  - "Grow — g-r-o-w" → **ow** at the end

### Word Building (5 min)
- Build long 'o' word chains:
  - **home → dome → done → bone → stone**
  - **road → load → loaf → loan**
  - **grow → slow → show → snow**

### Dictation (5 min)
- Dictate 5 words:
  1. home
  2. road
  3. slow
  4. bone
  5. coat
- Lucas writes, then identifies which long 'o' spelling pattern each uses.

- [ ] Can Lucas describe a character's appearance using adjectives?

- [ ] Can Lucas write from a character's perspective using "I"?
- [ ] How is Lucas progressing with long vowel spellings (ae, ee, oe)?
- [ ] Any areas needing additional focus in Week 3?

## Differentiation

| If struggling | If progressing well |
|---------------|---------------------|
| Return to third person ("Alba") if first person is confusing | Add dialogue: "I said, 'I can do this!'" |
| Provide sentence frames: "First, I ___. I felt ___." | Write a longer recount (5–6 sentences) with varied sentence beginnings |
| Focus on o-e and oa only | Include all four spellings in dictation; discuss when to use each |
