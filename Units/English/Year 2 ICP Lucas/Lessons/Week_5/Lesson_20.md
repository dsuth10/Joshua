---

## Learning Intentions

- **Reading:** I am celebrating my reading progress by revisiting a favourite book with fluency and expression
- **Writing:** I am completing my assessment task — writing a narrative using a known character
- **Spelling:** I am demonstrating my spelling knowledge in my assessment piece

## Success Criteria

- I can read a familiar text fluently and with expression
- I can complete the assessment task: a written narrative with sequenced events, punctuated sentences, topic-specific vocabulary, and correct spelling
- I can demonstrate my progress from the beginning of the unit

---

## Reading (≈15 minutes)

> **Note:** Reading time is shortened today to allow more time for the assessment task.

### Celebration Reading (10 min)
- Lucas chooses: either read today's new book OR revisit his favourite Alba book.
- Read aloud with fluency and expression.
- Teacher aide notes reading progress compared to Lesson 1:
  - Decoding accuracy
  - Fluency and expression
  - Self-correction
  - Confidence

### Reflection (5 min)
- "Think about when you first read *Lost* in Week 1. What was hard then that is easy now?"
- "Which book was your favourite? Why?"
- "What's one thing you've learned about reading that you're proud of?"

---

## Writing (≈30 minutes)

> **Note:** Writing time is extended today for the assessment task.

### Assessment Task Setup (5 min)
- Teacher aide introduces the assessment task formally:
  - **"Create a written story using a known character from a narrative text you have read."**
- Clarify expectations:
  - The story should have a beginning, middle, and end
  - It should include a character, setting, problem, and solution
  - Use punctuated simple and compound sentences
  - Use descriptive vocabulary
  - Spell words as best you can using the phonics patterns you've learned
- Lucas may use his published story from Lesson 19 as his assessment submission if it meets the criteria, OR he may write a new story.

### Assessment Option A — Submit Published Story (if applicable)
- If Lucas's published story from Lesson 19 meets the criteria, it can be submitted as the assessment.
- Lucas re-reads it one final time.
- Teacher aide confirms it demonstrates the required elements.

### Assessment Option B — Write a New/Different Story (25 min)
- If a new story is needed or if the teacher prefers independent assessment conditions:
- Lucas may use his story map or plan a new brief narrative.
- Lucas writes independently. Teacher aide may:
  - Read the task instructions aloud
  - Encourage and reassure
  - **NOT** assist with content, spelling, or punctuation (this is the assessment)
- Allow the full time for writing. Encourage Lucas to re-read his story when finished.

### Assessment Checklist (for teacher aide to note)
| Criterion | Evidence | Level |
|-----------|----------|-------|
| Creates a written text to narrate for an audience | | |
| Events are sequenced (beginning, middle, end) | | |
| Uses text structures to organise and link ideas | | |
| Punctuates simple sentences | | |
| Punctuates compound sentences | | |
| Uses topic-specific vocabulary | | |
| Uses descriptive vocabulary | | |
| Writes with legible unjoined letters | | |
| Spells words with regular patterns | | |
| Attempts less common spelling patterns | | |

---

## Spelling (≈15 minutes)

### Spelling Within Assessment (integrated)
- Spelling is assessed within the written narrative.
- No separate dictation today — the assessment piece IS the spelling evidence.

### Phonics Knowledge Reflection (5 min)
- After the assessment is complete, briefly review the phonics journey:
  - "In Week 1, you were working on CVC words like *got* and *ran*."
  - "Now you can read and spell words like *brave*, *flight*, and *ground*!"
- Teacher aide records any notable spelling achievements or patterns still being developed.

### Unit Wrap-Up (10 min)
- **Celebrate the entire unit!**
  - Count the books Lucas has read (12 Alba + 8 second series = 20 books!)
  - Look at the published story — compare it to the first sentences written in Lesson 1
  - Acknowledge growth: "Look how far you've come!"
- Lucas chooses one thing he's most proud of from the five weeks.
- Teacher aide provides positive, specific feedback.
