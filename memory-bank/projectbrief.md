# Project Brief: Joshua Educational Content Management System

## Project Overview
Joshua is a comprehensive educational content management system designed for Australian teachers, focusing on curriculum-aligned lesson planning, assessment creation, and resource management. The project integrates Australian Curriculum v9 standards with practical teaching materials, including C2C (Queensland) lesson conversion support and interactive history resources.

## Core Purpose
- Provide curriculum-aligned educational content for Australian teachers
- Automate lesson plan generation and assessment creation
- Manage educational resources across multiple learning areas
- Support both primary and secondary education levels
- Convert C2C (Queensland) lesson plans to Markdown for version control and reuse

## Key Components
1. **Curriculum Data Management**: AC v9 curriculum mapping and validation (1,395 descriptors across 8 learning areas)
2. **Unit Planning**: Structured lesson sequences and teaching materials (English, HASS, Science, Maths)
3. **Assessment Tools**: Automated assessment generation, Microsoft Forms import format, and NAPLAN marking rubrics
4. **Resource Library**: Educational assets, presentations, interactive history hubs, and multimedia content
5. **AI Skills Integration**: Specialized tools including curriculum-master, english-lesson, docx-to-markdown, and NAPLAN marking
6. **Australian History Hub**: Interactive web-based resource for federation-era figures (Henry Parkes, Vida Goldstein, Edmund Barton, Alfred Deakin, John Quick, Mary Lee)

## Target Users
- Primary school teachers (Foundation to Year 6)
- Secondary school teachers (Years 7-10)
- Curriculum coordinators
- Educational content developers

## Learning Areas Covered
- English
- Mathematics
- Science
- Humanities and Social Sciences (HASS)
- Technologies
- The Arts
- Health and Physical Education

## Technical Foundation
- Node.js-based tooling (docx, pptxgenjs, React, Playwright, Sharp)
- Python automation scripts (curriculum processing, validation, conversion)
- Microsoft Office integration (Word, PowerPoint, Forms)
- Git version control
- JSON-based data structures
- HTML/CSS for interactive educational sites (e.g., Australian History Hub)

## Project Goals
1. Complete AC v9 curriculum coverage for all learning areas
2. Develop comprehensive unit plans for each year level
3. Create automated assessment generation tools
4. Build resource management system
5. Establish teacher-friendly workflows
