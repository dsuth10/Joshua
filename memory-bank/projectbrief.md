# Project Brief: Joshua Educational Content Management System

## Project Overview
Joshua is a comprehensive educational content management system designed for Australian teachers, focusing on curriculum-aligned lesson planning, assessment creation, and resource management. The project integrates Australian Curriculum v9 standards with practical teaching materials.

## Core Purpose
- Provide curriculum-aligned educational content for Australian teachers
- Automate lesson plan generation and assessment creation
- Manage educational resources across multiple learning areas
- Support both primary and secondary education levels

## Key Components
1. **Curriculum Data Management**: AC v9 curriculum mapping and validation
2. **Unit Planning**: Structured lesson sequences and teaching materials
3. **Assessment Tools**: Automated assessment generation and marking rubrics
4. **Resource Library**: Educational assets, presentations, and multimedia content
5. **AI Skills Integration**: Specialized tools for content processing and generation

## Target Users
- Primary school teachers (Foundation to Year 6)
- Secondary school teachers (Years 7-10)
- Curriculum coordinators
- Educational content developers

## Learning Areas Covered
- English
- Mathematics
- Science
- Humanities and Social Sciences (HASS)
- Technologies
- The Arts
- Health and Physical Education

## Technical Foundation
- Node.js-based tooling
- Python automation scripts
- Microsoft Office integration (Word, PowerPoint, Forms)
- Git version control
- JSON-based data structures

## Project Goals
1. Complete AC v9 curriculum coverage for all learning areas
2. Develop comprehensive unit plans for each year level
3. Create automated assessment generation tools
4. Build resource management system
5. Establish teacher-friendly workflows
