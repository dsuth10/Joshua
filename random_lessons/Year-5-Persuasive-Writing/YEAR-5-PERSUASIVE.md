# Year 5 Persuasive writing - PEEL Structure

## Learning Goal

Students will learn how to structure persuasive paragraphs using the PEEL method (Point, Elaboration, Evidence, Link) to create a convincing argument.

## Key Components

- **Lesson Plan**: Structured guide for the teacher.
- **Student Handout**: Practice sheet and examples.
- **PowerPoint**: Visual aid with color-coded examples.

## Color Coding

- **Point**: Blue (Soft Blue)
- **Elaboration**: Green (Forest Green)
- **Evidence**: Orange (Vibrant Orange)
- **Link**: Red (Bold Red)
